# .NET で学ぶ ArcGIS ネイティブ アプリ開発基礎（ハンズオン）

このハンズオン資料は、2026 年 10 月 30 日（金）に実施する「.NET で学ぶ ArcGIS ネイティブ アプリ開発基礎（ハンズオン）」のイベントで使用するために作成した資料です。  
前半ではネイティブ アプリでのデータ表示方法を紹介し、後半では実際に ArcGIS Maps SDK for .NET を使って WPF アプリケーションをコーディングする流れを体験するハンズオン資料です。  

## 事前準備
- [Visual Studio サブスクリプション](https://visualstudio.microsoft.com/ja/subscriptions/)を用いてハンズオンを行います。
- ハンズオンは[演習テキスト](./HandsOn/README.md) に沿って進めます
